Welcome to the QLC+ wiki and thank you for your interest in this growing project.
Here you can find information about translating and compiling QLC+ on several platforms.

## HOWTO translate QLC+
At the moment, QLC+ is translated in german, spanish, italian, finnish and french.
If your langiage is not supported, please contact the developers and request the addition of it.
Otherwise here's a quick guide to contribute on an existing translation:
* create an account on GitHub
* fork qlcplus (guide: https://help.github.com/articles/fork-a-repo)
* download and install Qt Linguist. It comes with Qt (or Google it)
* open the _xx.ts file for your language
* translate, translate, translate, save
* when you're done send a pull request with your changes
